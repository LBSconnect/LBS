Security Overview

Work-A-Beez security controls should be documented and verified in these areas:

  • tenant isolation;
  • role-based access;
  • password storage;
  • multi-factor authentication;
  • authorized-device controls;
  • encryption in transit;
  • encryption at rest;
  • backups and restoration testing;
  • secure software development;
  • dependency and vulnerability management;
  • logging and monitoring;
  • incident response;
  • personnel access;
